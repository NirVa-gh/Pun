## Описание проекта

### Сетевая архитектура (Photon):
- **Photon PUN/Fusion** — реализация multiplayer через Photon Networking
- Room-based система: создание, присоединение, листинг комнат
- Мастер-клиент авторитарная модель для критичной логики
- Peer-to-peer синхронизация для non-critical данных
- Автоматическая реконнекция при потере соединения

### Синхронизация игроков:
- **PhotonView** + **PhotonTransformView** — синхронизация позиции и вращения
- **PhotonAnimatorView** — синхронизация анимаций через параметры
- Interpolation и extrapolation для плавного движения
- Компрессия данных для минимизации трафика
- Ownership transfer для подбираемых предметов

### Система комнат и лобби:
- Создание приватных/публичных комнат
- Кастомные свойства комнат (max players, game mode, map)
- Быстрый matchmaking через Room Properties
- Спектраторы и зрительский режим
- Автоматический переход между лобби и игровой комнатой

### RPC и события:
- **PunRPC** — удалённый вызов методов на всех клиентах
- **RaiseEvent** — кастомные сетевые события с опциями доставки
- Targeted RPC для конкретных игроков
- Buffered RPC для новых подключившихся игроков
- Приоритизация критичных событий

### Игровая логика:
- Синхронизация состояния игры через Custom Properties
- Wave Manager с сетевой синхронизацией спавна
- Инвентарь и предметы с сетевой валидацией
- Боевая система с hit detection на сервере
- Scoreboard и статистика в реальном времени
